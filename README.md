# PC Remote Control Server
This is the server program for the PC Remote control project, it comes together with a [mobile application](https://github.com/theAester/PCRemoteControl.git).

# Installation and usage
This is a python project so just download and unzip this repository to a folder, install [python](https://python.org), open your terminal (or cmd on windows 10 and below) navigate to the folder and run
```shell
python main.py
```
This will launch your browser and display the helper page

In it you can find instructions and help on how to connect to the server from your mobile application. Including local IP addresses and the connection password.
